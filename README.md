# ImageConverter

Простой конвертер изображений в WebP для Windows. Скрипт принимает путь к корневой папке, рекурсивно обходит все вложенные каталоги и конвертирует найденные изображения с помощью [Sharp](https://sharp.pixelplumbing.com/).

## Возможности

- рекурсивный обход всех подпапок;
- поддержка JPG, JPEG и PNG;
- конвертация в WebP с качеством 85;
- автоматический поворот изображения с учётом EXIF;
- корректная работа с пробелами и кириллицей в путях;
- пропуск файла, если WebP с таким именем уже существует;
- проверка созданного WebP перед удалением исходника;
- посторонние файлы и уже существующие WebP не изменяются.

> [!WARNING]
> После успешной конвертации и проверки WebP исходный JPG, JPEG или PNG удаляется. Если WebP уже существует или во время обработки произошла ошибка, исходник остаётся на месте.

## Требования

- Windows;
- [Node.js](https://nodejs.org/) с npm.

## Установка

Клонируйте репозиторий и установите зависимости:

```powershell
git clone https://github.com/sitesmaker/ImageConverter.git
cd ImageConverter
npm install
```

## Запуск

### Через проводник

1. Запустите `converter.bat` двойным щелчком.
2. Вставьте полный путь к корневой папке с изображениями.
3. Нажмите Enter.
4. Дождитесь итоговой статистики.

Также можно перетащить нужную папку на файл `converter.bat`.

### Из командной строки

```bat
converter.bat "D:\Фото товаров\Насосы"
```

Путь рекомендуется заключать в кавычки, особенно если в нём есть пробелы.

## Как проходит обработка

Для каждого JPG, JPEG или PNG создаётся WebP в той же папке и с тем же базовым именем:

```text
Каталог
├── фото.jpg
└── Подпапка
    └── изображение.png

После успешной обработки:

Каталог
├── фото.webp
└── Подпапка
    └── изображение.webp
```

В конце программа выводит количество успешно обработанных, пропущенных и завершившихся ошибкой файлов.

## Настройки

Основные параметры находятся в `converter.js`:

```js
const WEBP_QUALITY = 85;
const ALLOWED_EXTENSIONS = [".jpg", ".jpeg", ".png"];
```
